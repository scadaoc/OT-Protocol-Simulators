# OT-Protocol-Simulators

A collection of OT protocol simulators built for the [Caldera-OT blog series](https://medium.com/@laiqkhan559) on Medium.

Each folder contains a standalone simulator you can run locally as a lab target for OT security research, testing, and learning.

## Protocols

| Protocol          | Status            
|-------------------|-----------------
| Modbus            | Available    
| BACnet            | Coming soon  
| S7comm            | Coming soon  

More protocols will be added as the blog series progresses.
